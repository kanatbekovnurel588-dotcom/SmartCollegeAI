# SmartCollege AI — Умный контроль бюджета колледжа

**SmartCollege AI** — веб-приложение для анализа расходов колледжа, выявления перерасхода бюджета и поиска возможностей для экономии.

## 🎯 Цель проекта

Упростить анализ расходов колледжа и помочь эффективнее распределять финансовые ресурсы.

## ✨ Возможности

- Анализ общих расходов по категориям.
- Загрузка и обработка CSV-файлов.
- Сравнение расходов за разные месяцы.
- Визуализация данных с помощью графиков.
- Предупреждения о значительном росте расходов.
- Рекомендации по экономии бюджета.
- Настройка целевого процента экономии.
- Экспорт отчёта с результатами анализа.

## 🛠 Используемые технологии

- **Python** — основная логика приложения.
- **Streamlit** — создание веб-интерфейса.
- **Pandas** — обработка и анализ данных.
- **CSV** — формат входных данных.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <ССЫЛКА_НА_ТВОЙ_РЕПОЗИТОРИЙ>
cd SmartCollegeAI
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Установка библиотек

```bash
python -m pip install streamlit pandas
```

### 4. Запуск приложения

```bash
python -m streamlit run app.py
```

После запуска открой адрес, указанный в терминале. Обычно это `http://localhost:8501`.

## 📊 Пример использования

1. Введи расходы вручную или загрузи CSV-файл.
2. Просмотри общую сумму и распределение расходов.
3. Сравни показатели за разные месяцы.
4. Изучи предупреждения и рекомендации по экономии.
5. Скачай отчёт, если эта функция доступна в текущей версии приложения.

## 🔍 Принцип работы

Приложение анализирует табличные данные, рассчитывает показатели расходов и применяет правила для выявления отклонений и формирования рекомендаций.

Текущая версия представляет собой прототип аналитической системы. Она не использует обученную модель искусственного интеллекта.

## ⚠️ Ограничения

Точность результатов зависит от корректности входных данных. Для демонстрации используются примеры расходов, а не реальные финансовые данные колледжа.
